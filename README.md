## 特性

-   **沉浸阅读**：无边框窗口、黑白灰主题、亮暗色一键切换（View Transitions 平滑过渡）
-   <span style="font-weight: 650;">即时编辑</span>：可视化编辑MarkDown，快捷菜单。
-   **双视图**：渲染预览 / 源码高亮（highlight.js），均支持左侧目录导航与滚动同步
-   **舒适排版**：字号调节（滑动动画）、铺满模式、悬浮滚动条
-   **多标签页**：鼠标中键关闭标签，与浏览器操作习惯一致；标签可拖出成独立窗口、拖回合并，窗口内也可拖拽排序
-   **最近打开**：首页最近文档列表，支持单条删除与一键清空
-   **文件关联**：双击 `.md` / `.markdown` / `.mdown` / `.mkd` 直接打开（单实例转发）
-   **文件夹右键菜单**：资源管理器里选中文件夹右键即可「Open with OpenMD」，直接打开为工作区
-   **自定义安装器**：独立安装/卸载向导，安装时可选关联 .md 文件与添加文件夹右键菜单，卸载时自动清理

## 技术栈

| 层级 | 技术 |
| --- | --- |
| 前端 | React 19 · TypeScript · Chakra UI v3 · Vite |
| 后端 | Rust · Tauri 2 |
| 渲染 | markdown-it · highlight.js · DOMPurify |

## 开发

环境要求：Node.js 18+、Rust、WebView2（Windows 10/11 一般预装）。

```bash
pnpm install
pnpm tauri dev
```

## 构建

仅支持 Windows。

### 主程序

```bash
pnpm tauri build
# 产物：src-tauri/target/release/openmd.exe
```

### 安装包（安装器 + 卸载器，Windows）

发布走自定义安装向导。两个脚本都基于自身位置推导仓库路径，仓库放在任何目录下
都能直接运行，无需修改脚本。

需依次构建三个工程：

```powershell
# 1. 构建主程序
pnpm install
pnpm tauri build        # 产出 src-tauri/target/release/openmd.exe

# 2. 构建卸载器
cd uninstaller
pnpm install
pnpm tauri build
cd ..

# 3. 打包 payload 并构建安装器
cd installer
pnpm install
.\pack-payload.ps1      # 将 openmd.exe + md-file.ico + icon.ico + uninstOpenMD.exe 打进 payload.zip
.\build-installer.ps1   # 产出 OpenMD_{version}_Windows_x86_64.exe
```

## 项目结构

```
├── src/            # 前端源码（React）
├── src-tauri/      # 主应用 Rust 后端
├── crates/         # 多工程共用的 Rust 库
│   └── openmd-shell-verb/  # Windows 资源管理器集成（文件关联 + 文件夹右键菜单），主程序/安装器/卸载器共用
├── installer/      # 安装向导（独立 Tauri 工程）
│   ├── pack-payload.ps1
│   └── build-installer.ps1
├── uninstaller/    # 卸载程序（独立 Tauri 工程）
├── docs/           # 界面截图（README 预览图）
└── public/         # 静态资源（Logo、字体等）
```
